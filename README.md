# Live TV & Radio (PWA)

Free live TV, radio and local media player. Urdu / English, themes, favorites, recording.

## Files
- index.html — the whole app
- manifest.json — install profile
- sw.js — service worker (offline shell, cached lists)
- offline.html / 404.html — shown when there is no internet
- favicon.ico, icon-192.png, icon-512.png, icon-maskable-512.png, apple-touch-icon.png, favicon-32.png — app icons
- .nojekyll — tells GitHub Pages to serve files as they are

## GitHub Pages
1. Upload ALL files to one repository, no folders needed (keep the same names).
2. Settings > Pages > Deploy from a branch > main > / (root) > Save.
3. Open https://YOURNAME.github.io/REPO/ on your phone and tap Install app.
